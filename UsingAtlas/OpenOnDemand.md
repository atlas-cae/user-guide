# Open OnDemand
This open-source resource that we integrated into Atlas allows use of the HPC on the web. We have

1. A File Manager
2. Job Composer and Viewer
3. System Analytics Viewer
4. Interactive Apps (if configured by the system)

## Using OOD
Navigate to [https://192.168.24.121](https://192.168.24.121). Proceed despite the warning. The page is safe - the warning is because of the use of self-signed certificates.

Login with your Atlas credentials. Viola - you have your dashboard. Enjoy the experience.
